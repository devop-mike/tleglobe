# tleglobe

A stylized 2D globe visualization for satellite tracking using TLE (Two-Line Element) data.

## Stack

- [D3.js](https://d3js.org/) — globe rendering via orthographic projection
- [satellite.js](https://github.com/shashwatak/satellite-js) — SGP4 propagation (planned)
- [world-atlas](https://github.com/topojson/world-atlas) — country geometry via TopoJSON

## Usage

Open `website/index.html` in a browser. No build step required.

- **Drag** to rotate the globe
- **Scroll** to zoom
